One word for the human an AI agent works for — the boss, client, or manager who signs off on the work:

> Signoffasaurus

The sign-off human, reimagined as a lumbering dinosaur: ancient, enormous, slow-moving, and unbothered — the one whose approval you wait on while the world moves on around them.

## Entry

`main.ts` writes the word, and nothing else, to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

```sh
node main.ts
```
